    About this project

    SHIELD 2.0 is an academic AAD (AI-Assisted Development) project that combines cybersecurity awareness with practical web development. It pairs a local, pattern-based message analyzer with a user-education layer — a threat library, safety tips and an interactive quiz — so the same tool that flags a suspicious message also explains why it looks that way.

    The detector runs entirely in the browser using a deterministic, rule-based scoring engine — it does not use machine learning, and no message content is sent to a server. The analyzer is written as a single modular function so a real AI or backend API could be connected later without changing the rest of the app.

    Built as a college AAD project with the assistance of AI development tools, including Claude, Antigravity and ChatGPT, used during the design and coding process.
